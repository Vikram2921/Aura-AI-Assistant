# AURA — Your Intelligent Desktop Companion

AURA is an AI-powered Windows desktop companion designed to make everyday computer interactions more natural, intelligent, and productive.

Built with **Tauri, React, TypeScript, and Gemini Live**, AURA combines real-time voice conversations with a modern Dynamic Island interface that stays accessible without interrupting your workflow.

### Key Features

- **Dynamic Island:** A compact, interactive desktop interface with smooth animations and quick controls.
- **Real-Time AI Conversations:** Natural voice interactions powered by Gemini Live.
- **Custom Personalities:** Create and switch between different AI personalities, moods, and conversation styles.
- **Intelligent Memory:** Context-aware memories, facts, and ideas with automatic expiration and efficient retrieval.
- **Desktop Control:** Manage volume, brightness, applications, system settings, and other Windows functions.
- **Screen Awareness:** Help AURA understand selected areas of your screen.
- **Smart Productivity:** Manage reminders, alarms, tasks, and calendar events using natural language.
- **Browser Automation:** Open websites, search the web, and manage browser tabs.
- **Extensible Tools:** A modular architecture for adding new AI capabilities and integrations.
- **Privacy-Focused:** Local settings, secure credential storage, and controlled access to system functions.

### Our Vision

AURA aims to become more than a traditional voice assistant. It is designed to be a personal desktop companion that understands context, adapts to your preferences, and helps you interact with your computer effortlessly.
