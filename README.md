# AURA — Your Intelligent Desktop Companion

**AURA** is a personal AI desktop companion for Windows that brings intelligence, productivity, and natural interaction directly to your desktop.

Unlike traditional AI assistants, AURA is designed to feel like a companion that can understand you, remember important details, adapt to your personality, interact with your computer, and help you complete everyday tasks.

## Features

### 1. Interactive Dynamic Island
- A compact, floating interface that stays accessible on your desktop.
- Smooth expansion, collapse, and transition animations.
- Animated AI mascot with different moods and speaking states.
- Quick access to conversations, system controls, notifications, and productivity tools.
- Interactive controls for volume, brightness, Wi-Fi, Bluetooth, and other Windows functions.
- Customizable appearance, positioning, and behavior.
- Smart notifications displayed directly below the island.

### 2. Real-Time AI Voice Conversations
- Natural, two-way voice conversations with low latency.
- Supports continuous conversations without repeating wake words.
- Configurable wake words for hands-free interaction.
- Multilingual conversations, including English and Hindi.
- Personality-aware responses with natural conversational styles.
- Intelligent command detection to handle simple actions without unnecessary AI requests.
- Voice-based interaction with desktop tools and applications.

### 3. Custom AI Personalities
- Create, customize, and manage multiple AI personalities.
- Define personality traits, communication styles, tone, and behavior.
- Switch personalities without losing important context.
- Personality Studio for creating detailed custom personas.
- Dynamic mood and emotional states.
- Different conversational relationships and roleplay experiences.
- Personalized greetings and interactions.

### 4. Intelligent Memory System
- Automatically identifies useful memories, facts, and ideas from conversations.
- Remembers important preferences and recurring information.
- Categorizes memories for better organization.
- Assigns intelligent expiration times, from minutes to permanent storage.
- Automatically removes expired or outdated memories.
- Retrieves relevant memories only when needed.
- Reduces unnecessary context usage to improve efficiency.
- Interactive memory graph showing relationships between memories, facts, and ideas.
- Allows users to view, edit, and delete stored memories.

### 5. Windows System Control
- Control speaker and microphone settings.
- Adjust system volume and screen brightness.
- Manage Wi-Fi and Bluetooth.
- Lock, sleep, restart, or shut down Windows.
- Switch between light and dark themes.
- Change desktop wallpapers.
- Launch and manage installed applications.
- View live CPU, RAM, and GPU information.
- Perform supported system actions through voice commands or the Dynamic Island.

### 6. Screen Awareness
- Understand information displayed on your screen.
- Select specific screen regions for analysis.
- Ask questions about text, images, applications, and visible content.
- Get contextual assistance based on your current activity.
- Explain errors, interfaces, and technical information.
- Control when AURA can access screen content.

### 7. Browser Interaction
- Open websites through natural language.
- Search Google, YouTube, and other supported platforms.
- Open, close, and manage browser tabs.
- Navigate websites using voice instructions.
- Assist with browsing, research, and everyday web activities.

### 8. Smart Productivity Tools
- **Calendar:** Create, view, update, and manage events.
- **Reminders:** Set reminders with configurable advance notifications.
- **To-Do Tasks:** Create, organize, update, and complete tasks.
- **Alarms:** Set and manage alarms.
- **Timers:** Start, pause, resume, and cancel timers.
- **Daily Planner:** View today's tasks, events, and progress in one place.
- **Smart Scheduling:** Schedule active notifications only when needed.
- **Activity Tracking:** Monitor task completion and daily progress.

### 9. Contextual Notifications
- Compact notifications connected to the Dynamic Island.
- Notifications for reminders, alarms, calendar events, and upcoming tasks.
- Confirmation messages when memories, facts, or ideas are saved.
- System action and tool execution feedback.
- Customizable notification behavior and appearance.
- Smooth animations without interrupting the current workflow.

### 10. Desktop Automation and Tools
- Execute supported desktop actions through natural language.
- Run authorized system commands silently in the background.
- Retrieve system information without opening terminal windows.
- Discover available capabilities and tools.
- Suggest additional tools when new capabilities would be helpful.
- Extend AURA with custom tools and integrations.
- Request permission before performing sensitive operations.

### 11. Personalized Dashboard
- Personalized welcome message.
- Interactive calendar with highlighted events.
- Today's activities with completion tracking.
- Real-time system usage information.
- Quick navigation to personalities, memory, planner, and settings.
- Clean, compact interface designed for everyday use.

### 12. Privacy and Customization
- Secure storage for API credentials and sensitive settings.
- User-controlled screen and system access permissions.
- Configurable memory retention and deletion.
- Customizable voice, personality, and assistant behavior.
- Local management of preferences and application settings.
- Control over automatic actions and AI interactions.

### 13. Application Updates
- Automatic detection of available updates.
- Dedicated update window with version information.
- Release notes and feature highlights.
- Download progress and update status.
- Option to download immediately or postpone updates.

---

## Vision

AURA is built around a simple idea: **your AI assistant should work with your computer, understand your preferences, and adapt to the way you work.**

Whether you are managing daily tasks, controlling Windows, having a conversation, browsing the web, or working on something complex, AURA aims to make the experience simpler, faster, and more personal.

**AURA — Your Desktop. Your AI. Your Way.**
